# CS350 Project Reflection

For this course, I built a thermostat system using a Raspberry Pi 4, a temperature sensor, LCD screen, buttons, and LEDs. The goal was to create a system that could monitor the temperature, allow the user to adjust the setpoint, and respond based on the current operating state. This project helped me better understand how hardware and software work together. One thing I learned pretty quickly is that even a small wiring issue can cause problems that initially look like something wrong with the code.

I think I did well with troubleshooting and testing each component before putting everything together. There were a few times I had to go back and check connections or make adjustments, but working through those problems helped me understand the system better. One area I could improve on is planning out some of the code earlier instead of making changes as I went. I also gained more experience using Python, Raspberry Pi documentation, GitHub, and the course lab resources, which I can use again for future projects. Learning more about state machines, GPIO controls, and integrating different hardware components will definitely carry over into other courses and even some of the troubleshooting I do at work. I tried to keep my code organized with separate functions, meaningful names, and comments where needed. Having the state machine diagram also makes it easier to understand how everything works and should help if I ever want to go back and make changes.



Project Artifacts: I chose the following two files for my portfolio because I think they best represent the work I completed throughout this course.

Thermostat.py: This is the Python code for my final thermostat project. It brings together the temperature sensor, LCD, buttons, LEDs, and state machine logic to create a working system.

CS350_Thermostat_State_Machine.drawio.pdf: This diagram shows the different operating states of the thermostat and how the system moves between them based on temperature readings and user input. It also helps explain the overall logic behind the Python code.
